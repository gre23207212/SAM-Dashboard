# Unitree Go2 Dashboard

An Electron-based desktop application for managing and controlling the Unitree Go2 robot dog.

## Download

Download the latest `.exe` from the [Releases](../../releases) page.

## Features

- Robot controls
- System monitoring
- Robot settings

## Built with

Electron, JavaScript, HTML and CSS.

## Requirements

Windows 10/11 and a Unitree Go2 robot.

This is an independent project and is not affiliated with Unitree Robotics.
